# ✈️ Airport Passenger Service Portal

A full-stack Airport Passenger Service Portal built using **React.js**, **Node.js**, **Express.js**, and **MySQL**. The application enables users to securely register, log in, search and book flights, track live flight status, manage bookings, and submit complaints through a responsive web interface.

## 🚀 Live Demo

- **Frontend:** https://airport-passenger-service-portal.vercel.app/
- **Backend:** https://airport-passenger-service-portal.onrender.com/

---

## ✨ Features

- 🔐 JWT-based User Authentication
- ✈️ Flight Search & Booking
- 📡 Live Flight Status
- 📖 My Bookings
- 📝 Complaint Management
- 📱 Responsive User Interface

## ⚙️ Local Setup

### Clone the Repository

```bash
git clone https://github.com/Akriti1331/Airport-Passenger-Service-Portal.git
cd Airport-Passenger-Service-Portal
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
